# Documentation Index

This is the public publication surface's `docs/` folder. It is not a mirror of the working repository's `docs/` — it carries only the specification and profile-status material intended for external use.

## Start here

- **[`docs/CONCEPTS.md`](CONCEPTS.md)** — the KEE conceptual tree: an informative, non-normative orientation map of how the pieces fit together.
- **[`docs/specs/`](specs/)** — every published specification baseline this repository carries, current and retained-historical.
- **[`docs/profiles/README.md`](./profiles/README.md)** — profile inventory, status, and cross-profile rules.

For governance, release process, and everything else behind how this repository's content is produced, see the root `README.md`.
